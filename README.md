# Packlight — Weather-Aware Packing Planner

**Pack smarter. Travel lighter.**

Packlight is a weather-aware packing planner that helps travelers prepare for their trips with personalized packing suggestions based on their destination, travel dates, weather conditions, and planned activities.

Instead of guessing what to pack, travelers can create a practical checklist tailored to their journey.

### Live Demo

**[Open Packlight](https://ipsaverma2811.github.io/packlight/)**

**[View GitHub Repository](https://github.com/IpsaVerma2811/packlight)**

---

## Features

- **Weather-aware recommendations** — Get packing suggestions based on forecast conditions.
- **Destination-based planning** — Look up a destination to plan your trip.
- **Activity-based packing** — Tailor your list to the activities you plan to do.
- **Interactive checklist** — Mark items as packed as you prepare.
- **Estimated packing weight** — Get an approximate weight for your packing list.
- **Copyable packing list** — Copy your checklist for easy reference.
- **Responsive design** — Use the planner on desktop or mobile devices.
- **Saved progress** — Keep checklist progress in your browser.

## Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Application logic and interactivity
- **Open-Meteo API** — Weather forecast data
- **Browser Local Storage** — Saves checklist progress
- **GitHub Pages** — Hosting and deployment

## Getting Started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/IpsaVerma2811/packlight.git
   ```

2. Open the project folder:

   ```bash
   cd packlight
   ```

3. Open `index.html` in your browser.

No build tools or package installation are required.

## How It Works

1. Enter your travel destination.
2. Select your travel dates and trip preferences.
3. Review weather-aware packing recommendations.
4. Check off items as you pack.
5. Use your personalized checklist to prepare for your trip.
